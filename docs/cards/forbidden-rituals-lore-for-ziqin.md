# Forbidden Rituals — lore for Ziqin (Member 5)

Background-only lore for the four Forbidden cards. Card-face descriptions live in `cards.json`
and are separate from these entries.

Tone: grave, restrained, mythology-neutral. Fallen / release, not evil / destruction.
Avoided: archive, catalogue, shelf, record, Eclipse, Fallen Archivist, named gods.

## sealed_pact — Sealed Pact — Forbidden Rituals

An oath an angel is forbidden to speak aloud. Binding it still steadies the hand for the climb,
though the cost is never only energy.

## blood_price — Blood Price — Forbidden Rituals

Some rites ask the servant to spend themselves so the fallen can be reached. The blow is meant to
break what holds them, not to unmake them.

## doom_sigil — Doom Sigil — Forbidden Rituals

The sigil was used to show where corruption clung hardest. Once marked, the fallen could be helped
instead of merely endured.

## iron_oath — Iron Oath — Forbidden Rituals

Sworn on cold iron against despair. The oath does not hide the wound; it keeps the bearer standing
long enough to finish the release.
